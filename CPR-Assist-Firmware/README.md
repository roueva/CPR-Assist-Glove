# Shortcuts only

This folder holds two Windows shortcuts for quick access to the live Arduino
sketches:

- `cpr_glove_new.lnk` -> `C:\Users\evaro\Documents\Arduino\cpr_glove_new`
- `cpr_glove_right.lnk` -> `C:\Users\evaro\Documents\Arduino\cpr_glove_right`

The tracked firmware source lives in `CPR-Assist-Firmware-LeftHand/` (for
cpr_glove_new) and `CPR-Assist-Firmware-RightHand/` (for cpr_glove_right).
Both must be kept in sync with the corresponding Arduino sketch folder by
hand — see `SKETCH_LOCATION.md` in each.
